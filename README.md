**Movie Recommendation System**

A content-based Movie Recommendation System built using Machine Learning and Streamlit.
This project recommends movies based on similarity of content using natural language processing techniques and provides an interactive, user-friendly web interface.

**Features**

> Select a movie and get similar movie recommendations
> Content-based filtering using cosine similarity
> Fast and dynamic recommendation generation
> Modern, responsive, and attractive UI
> Mobile-friendly design
> Web-based interactive application


**Tech Stack**

-Python
-Pandas & NumPy – Data processing
-Scikit-learn – Machine learning & similarity calculation
-Jupyter Notebook – Model development & experimentation
-Streamlit – Web application & deployment

**Machine Learning Approach**

-Text features (tags) are vectorized using CountVectorizer
-Cosine Similarity is used to measure similarity between movies
-Top similar movies are recommended based on similarity scores

The application is deployed using Streamlit Community Cloud, allowing easy access through a web browser without any local setup.
